# 装备环与格位

## 4→6→8→10 的常规成长

初始四格：前右 `FR`、右一 `R1`、左一 `L1`、前左 `FL`，顺时针组成环。每次扩容在后部对称插入 `R2/L2`、`R3/L3`、`R4/L4`。因此已有道具的槽位 ID 不变，所有格位重新等角分布；扩容后受影响的邻接关系需在界面中预览。`FR` 与 `FL` 永远是最前方两格，会随目标方位平滑转向。没有目标时保持最后朝向。

经营等级首次达到阈值时可选择增加一对格位，后续阈值再次提供。默认预期第 3、6、9 天前后到达 6、8、10 格，但玩家选择即时收益可延后。10 格是标准上限；12 格只留给未来活动模式覆盖 `BoardRules.MaxSlots`，常规道具与强化不产生第 11、12 格。

每格首版容纳一件道具。武器、护甲、发动机、生成器、收藏品都使用同一安装接口；消耗型针剂留在仓库，使用后不占格。多格大物品先不做，避免扩容、拖动和套组同时引入过多规则。合成品可以更强，但仍只占一格。

## 位置规则

- 相邻：环形上左右各一格。适合电路、护盾传导、武器增伤。
- 对位：偶数格下相隔 `N/2` 格。4、6、8、10 格都有确定对位，但扩容会改变对位对象；准备界面要预览变化。
- 前方：`FR`/`FL`。朝敌人转向，适合近战与远程开火方向；不是额外的免费武器栏。
- 后方：远离敌人的一侧。适合经济与保护道具，承担较少主动接触机会。

为避免“扩容导致所有已知连锁突然变化”的挫败感，扩容前必须显示格位重排预览及失去/获得的相邻、对位加成。确认后才能应用，并允许在当天准备阶段撤销一次。

## 格位自身的成长

格位是可强化的 `SlotInstance`，与上面装备的 `ItemInstance` 分离。格位有稳定 ID、等级、最多一个附魔效果、临时状态。道具换位时格位效果留在原槽；“随道具携带”的改造则属于道具实例，二者在 UI 中使用不同颜色。

初版三种来源：

1. **定期强化**：例如银色“选择一格，所装武器射程 +10%”；金色“前方双格的近战每次有效撞击获得护盾”；棱彩“所有对位格共享一次伤害加成”。
2. **消耗道具**：例如“槽位铭刻片”拖到某格，添加一次性格位附魔；来源包括特殊商店、事件与合成。
3. **套组奖励**：满足收藏条件后解锁全环效果；该效果来自套组状态，不占格位附魔槽。

格位升级价格按等级提高，初版每格最多 2 级。保留最多一个附魔可防止同格叠出不可读的触发链。

## 收藏套组

收藏品本身是道具，安装在格位上并带 `CollectionSetId`。套组只计算装备环内的不同成员，不计算仓库。第一版采用 2/4 件阈值；后期 8 件“全环收藏”只在至少 8 格时可完成，10 格允许放入额外的引擎或武器。套组奖励应改变玩法，而非只给巨额百分比：例如“每个相邻的馆藏首次触发时获得能量；满 8 件时每 5 秒复制一次最弱馆藏的效果”。复制必须遵守触发预算与循环保护。

仓库中可查看套组缺件、已拥有成员、还缺的格位数与下一档奖励。扩格是收藏路线的重要投资，但少格高强度流派仍应能取胜。
