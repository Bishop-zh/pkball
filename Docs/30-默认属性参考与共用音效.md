# 30. 默认属性参考与共用音效

## 使用

主播模式的默认数值显示为「8（默认）」等参考文本。输入框仍留空，保存时继续沿用目录，而不会自动变成覆盖值。输入数值覆盖，清空恢复默认。参考是一级基础值；等级、叠层及选手增伤后的结果看「成长与吸收」页。音量、效果倍率、冷却倍率清空恢复1，叠层次数清空恢复0。

攻击表现页选择「射击 / 释放音效」，命中效果页选择「命中音效」。两处有试听按钮与0～1音量倍率，可沿用默认、静音、或选择任意目录声音。试听一次播放一个声音，关闭配置页停止试听。

已制作11个原创程序合成的原型音效：刀剑/重锤挥击、弓弩/轻型枪/炮弹/激光发射、金属命中、毒液、火焰、护盾和治疗铃音。它们是简单占位声音，可以替换成后续正式素材。

## 扩展音效

- WAV/OGG等Unity支持的音频放到 `Assets/PKBall/Resources/Audio/Sfx`。
- 文件名是稳定音效ID，不能重复；子文件夹也会被读取。
- 在 `Resources/Data/sounds.json` 中可配置相同ID的中文名、类别和基础音量。不填写元数据时仍自动加入列表，使用文件名显示。
- 更新后重新进入Play即可读取。无需改界面脚本或增加枚举。
- 道具目录的 item.releaseSoundId / hitSoundId 指定默认声音，releaseVolume / hitVolume 是道具基础音量。空ID按武器形态、射击表现和状态效果推断；none静音。
- 对战预设只保存ID和倍率；运行时克隆道具，主模式目录不会被覆盖。既有对局存档结构不变。

`Tools/GeneratePrototypeAudio.py` 可以重建这组原创音效。它会覆盖本组同名WAV及sounds.json，因此正式美术替换后不要直接运行生成器。

## 架构与触发

1. PrototypeBroadcastDefaults：数值参考解析，与输入覆盖分离。
2. PrototypeAudioLibrary：目录加载、稳定ID、中文名、默认声音映射；素材只在首次使用时读取。
3. PrototypeAudioPlayback：16个池化AudioSource，共用二维音效播放，不为每次攻击创建物体。
4. PrototypeCombatPresentation：在释放动画启动时播放一次声音，齐射不按每个视觉弹体重复播放。
5. PrototypeAttackPayload：释放时快照命中音效ID和音量，伤害到达时由ApplyPayload播放。远程飞行与近战延迟不会提前播放命中音效。
6. 主模式及主播模式使用上述同一路径；UI试听也复用播放组件。

战斗音效按真实时间限制：相同声音至少间隔45毫秒，每100毫秒最多启动10个声音，最多16个并发音源。超量声音合并或略过，绝不排队延迟伤害事件。两倍速增大事件频率，声音不变调。毒火持续伤害每次结算不重复播放短音效，避免密集噪声。

当前无背景音乐、空间定位或总音量设置菜单；预留独立音效播放组件，后续可接AudioMixer和分类音量。
目录版本2、对战预设版本3、角色预设版本2保留旧版本读取。旧格式没有音量字段，迁移时设为1；新格式的0音量会原样保留。音频导入器对Sfx目录自动设置单声道、PCM解压加载与预加载。
