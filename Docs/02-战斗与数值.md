# 战斗与数值

所有数值为原型初值，统一放入 `CombatBalance` 配置。使用无量纲的生命/速度数值，勿直接把 Unity Rigidbody 的质量等同于生命上限。模拟以固定步长进行；渲染插值与战斗结算解耦。

## 角色与运动

首版角色为一块圆角方块/圆盘，平面移动，碰墙反弹。玩家战前选择方向和力度。移动方向由碰撞与反弹改变；装备环的面向敌人角度独立于移动速度。每个角色只有一个物理主体，格位是挂载的武器与命中区域，不给每格各建一个自由刚体。

角色定义包含最大生命 H、当前生命、速度属性 S、能量 E、基础半径、转向速率。以最大生命决定有效质量：`M = clamp((H / 100)^0.5, 0.70, 2.50)`。实际目标移动速度：`V = clamp(4.0 × (S / 100) / M, 1.5, 12.0)`，初始 S=100、H=100、V=4。发射力度把初始速度缩放到 50%～100%。生命上限 400 且 S=100 时，质量 2、速度 2；同质量下把 S 提到 200，速度回到 4。角色受伤不会改变 M，防止越受伤越快。

速度属性表示“推动能力”而非固定物理速度。碰撞瞬间可高于或低于目标速度，随后按每秒 25%～40% 回归目标速度。最大生命高的实体更难被击退，但不天然获得全部撞击优势；质量进入伤害时使用次线性函数。

## 碰撞伤害

仅在相向接触且相对法线速度大于 1.5 时造成块体撞击伤害。对同一对角色的撞击结算有 0.25 秒保护窗，以阻止接触抖动多次计伤。原型公式：

`冲击强度 I = max(0, 相对法线速度 - 1.5)`

`基础撞击伤害 D = (4 + 1.8 × I) × sqrt(攻击方有效质量) × (1 + 撞击伤害加成)`

`最终撞击伤害 = D × 受击方撞击承伤倍率 × 近战武器撞击倍率`

近战武器撞击倍率默认 1.0，仅具有“冲撞”标签且安装在此次接触方向覆盖的格位时生效。初版区间 1.15～1.40。普通近战武器不会无条件加强全身撞击。受击方撞击承伤倍率默认为 1.0；护撞道具可降低到 0.65，所有来源合计下限 0.4。撞击伤害每次上限建议为目标最大生命的 18%，先验证再调整。

高生命路线以质量、抗击退和生存取得更多接触机会；高速路线以相对速度取得爆发。二者都可走撞击，但投资方向不同。全局终伤上限和保护窗防止一次碰撞秒杀与重复触发。

## 武器攻击

| 类别 | 原型规则 | 初始数值参考 |
| --- | --- | --- |
| 近战 | 冷却就绪且目标进入武器攻击距离、角度范围、无遮挡才攻击；目标离开范围时不空挥 | 距离 1.5～2.5，冷却 0.8～1.8 秒，伤害 8～18 |
| 远程 | 冷却就绪且有可见敌人时直接朝敌人当前位置瞄准并发射；无目标则保留就绪状态。投射物有飞行时间，可被移动躲开 | 冷却 2.8～5.0 秒，伤害 12～25，射程 8～14 |
| 冲撞型近战 | 满足近战范围可普通攻击；装备方向命中时增强一次块体碰撞伤害 | 冷却 1.3 秒，撞击倍率 1.25 |

武器独立的冷却、射程、角度、目标规则均来自定义数据。远程“直接瞄准”不等于必定命中；先用直线弹道和可躲闪飞行时间。多个远程武器可共享目标缓存，避免每件每帧搜索。前方双格的部件外观与朝向持续追踪敌人；其他格位保持环上的本地角度。近战是否覆盖碰撞方向按命中法线与格位扇形判断。

## 能量与终局压力

能量初始 100；每秒移动消耗 `0.8 + 0.15 × 实际速度`，有效撞击额外消耗 `2 + 0.5 × I`。能量为 0 后，移动每米损失 `0.5 × (1 + 超时系数)` 生命。45 秒后双方每秒承受从 0 线性升到 3 的终局压力，90 秒比较生命比例。某些防御或锻体效果可以减轻能量损失，但不能完全关闭超时压力。

## 物理与数值边界

- 体型半径标准 0.55，锻体变动初版限制在 0.40～0.85；外观缩放必须与碰撞半径同步。
- 实际速度上限 12；超高速时使用连续碰撞检测或额外的扫掠检查，防止穿透。
- 碰撞伤害、普通近战和投射物分别记账；战斗结果页展示三者贡献。
- 两个主体互撞只生成一次接触记录，由战斗服务为双方各算一次伤害，不依赖两个碰撞回调的调用顺序。
