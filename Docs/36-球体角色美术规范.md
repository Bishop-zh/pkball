# 球体角色美术规范

本规范以用户最新参考图为形态基准。角色是完整的大圆球，圆心具有连续球面体积。风格是奇幻机械手绘卡通：近黑深海军蓝粗外描边，内部细线，左上暖光，冷钢与暖黄铜，柔和球面阴影，发光眼睛。

## 必须保持的形态

球面占主体可见面积 70～85%，附件的视觉面积不超过 25～30%。比例按最终缩略图的视觉占比检查，不以透明画布面积计算。圆心核心不得被层层装备遮住，轮廓仍应一眼读成圆球。角、帽、冠、护目镜、面罩、铆钉和口袋应小而紧贴球面；每个角色只保留两到三处识别配件。

没有独立躯干、腰、手、臂、腿或脚。禁止以胖人形、站立玩偶或小人骑球替代球体。禁止拖地长披风、大面积竖直身体、杂乱尖刺、独立肩膀与靴子。参考图中的大武器可以帮助理解材质与角色主题，本项目常态造型将其缩为小贴身饰件、小口袋或纹章，不绘制持武器的人形。

## 六角色合批

六角色统一在 3 列 × 2 行图集中生成，依配置约定从左至右、从上至下映射资源 ID。球径、视角、光源、外描边粗细与材质笔触一致；通过球面颜色、眼睛、角帽和贴身配件区分，不能靠增加四肢或拉长躯干区分。

每格最终裁为 512×512 真透明 Alpha PNG，球体居中，边缘保留至少 6% 安全余量。角色和饰件不得跨格，不得带邻格残片。源图集保存到 Art/Generated，运行资源使用 Resources/Art 下稳定 ID；实际六角色资源映射在下表登记。

## 生成与验收

出图不能有背景、地面、投影地板、底牌、徽章、文字、水印或棋盘格伪透明。允许球面内部贴身阴影，不允许独立地面阴影。保留冷钢与暖黄铜材质的手绘变化，避免照片写实、像素风、硬科幻或纯平涂无描边。

先在透明底、深色底、浅色底分别检查 Alpha 边缘与裁切，再在 128×128 缩略图检查圆球轮廓、眼睛和少量饰件是否清楚。逐个检查圆心核心、附件面积、图集越界及任何独立四肢；任一项违反造型边界就重新生成或修正，不能因为配色符合而接收人形版本。

最终在 Unity 角色头像与战斗球体入口检查识别性和裁切；后台测试优先使用 Unity 离屏 RenderTexture 或项目截图入口，保持用户前台不受影响。美术检查结果单独记录，不用代码测试通过替代视觉验收。

六角色主题仅用于球面材质和贴身装饰：灰烬骑士用小钢盔与火光眼；瘟疫炼金师用小面罩与药袋；圣钟守卫用小钟纹与金色冠片；青竹剑灵用竹叶纹与微型剑饰；赤丹药修用丹砂纹与贴身葫芦；霜山龟灵用圆球龟甲纹与短霜角。圣钟、飞剑、炼丹炉等装备不作为大手持武器覆盖球体。
