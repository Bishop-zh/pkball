# 六角色与装备池

获取来源与首领身份独立：acquisition=ShopAndLoot(0)允许商店与怪物掉落，WildOnly(1)只允许怪物获胜掉落，不由事件或生产获取；bossItem决定首领道具身份，固定4级且不能合成。WildOnly普通装备可1～4级，并可合成、突破。legacy bossExclusive只兼容为野外来源，不代表新首领身份。

死神镰刀：野外首领固定4级；死神披风：野外普通，可1～4级，无敌1/1/1/1.5秒。史莱姆粘液：野外普通；八团史莱姆改为一个固定4级史莱姆核心及七件粘液。核心每次释放增加本场最大生命5%，并造成自身最大生命10%的伤害。

18件装备和史莱姆核心均具备独立fallback资产，JSON损坏时稳定ID不丢失；正式图像可按iconId及对应monster图像ID替换。
