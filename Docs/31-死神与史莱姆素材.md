# 死神与史莱姆素材

本批素材由内置 imagegen 生成，遵循《16-统一美术风格与主菜单》的奇幻机械卡通方向：深海军蓝轮廓、钢与黄铜材质、左上柔和高光；死神为深紫与黄铜，史莱姆为绿色黏液与青蓝高光。角色及道具保持独立轮廓，无文字、徽章或地面投影。

## 源图与运行时资源

正式源图：`Assets/PKBall/Art/Generated/reaper-slime-atlas.png`，1536×1024，RGBA。该源图位于美术目录，运行时加载六张独立裁切图；替换任一怪物或装备外观不需要替换整张图集，也不改变战斗数值。

裁切坐标为左、上、右、下，右下边界不包含在内。

| Resources 相对路径 | 源图裁切区域 | 输出 |
| --- | --- | --- |
| Art/monster_reaper.png | (0, 0, 525, 548) | 512×512 |
| Art/monster_slime.png | (525, 0, 1024, 548) | 512×512 |
| Icons/death_scythe.png | (1024, 0, 1536, 550) | 256×256 |

每一区域按 Alpha > 10 的主体边界去除外围透明区域，然后保持比例缩至画布边长的 87%，在透明画布上居中。仅执行裁切、缩放及透明画布排版，没有重绘主体或删除背景。死神与史莱姆之间的分界设为 x=525，避免此前 x=512 / x=530 造成的轮廓截断。

## 透明度与导入

源图 Alpha 为 0–254，930973 个像素完全透明（约59.2%）。六张切图均为真实 RGBA，四角与画布边缘完全透明；角色最小边距33像素，道具最小边距17像素，均超过6%要求。视觉检查确认镰刀、披风、黏液与骨符主体完整，死神右侧无史莱姆绿色残片，史莱姆左侧轮廓完整。

六张切图统一使用 Texture2D（textureType=0），与现有 Resources.Load<Texture2D> / Sprite.Create 的加载方式一致；Bilinear、sRGB、Alpha Is Transparency，关闭 mipmap，Wrap 为 Clamp。保留原 meta GUID，避免已有引用失效。源图导入设置独立保留，运行时不依赖它。

## 可替换范围与验证边界

角色资源 ID 为 monster_reaper / monster_slime；道具资源 ID 为 death_scythe / death_cloak / slime_mucus / bone_talisman。后续可以按同一文件名直接替换单张透明图，也可通过视觉定义配置更换图片引用。美术资源不承担装备效果、怪物属性或技能逻辑。
