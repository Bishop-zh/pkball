# 交互修复、历史对局与精力系统

更新日期：2026-10-03。正式项目：`C:/code/GameMake/PKBall`。

## 1. 装备环点击与拖放

左上方三个扇区无法点击的原因是角度命中检测仅向一个方向调整角度，负角度扇区被误判为区域之外。现在使用 `Repeat(鼠标角度 - 起始角度, 360)`，与扇区角度跨度比较，覆盖完整一圈。显示轮廓与真实命中区域保持一致，中心空洞及扇区间隙不接收格子事件。

8 格和 10 格布局中的每个开放扇区都验证了实际 GraphicRaycaster 最上层命中、背包拖放装备、点击卸下。

## 2. 战斗道具详情

我方、敌方格子均支持悬停约 0.5 秒显示详情。显示分类、等级、配置效果、实例成长、永久冷却强化、继承程序与药水配方、当前冷却和本场产物数量。我方另显示格子附魔。滚轮切换 1～4 级预览，不修改实际道具。

详情读取角色实际运行中的物品实例；武器额外显示带战斗倍率的主效果直伤（目标减伤前）。原配置伤害与实例成长单独展示。浮层不拦截鼠标，离开原格子后隐藏；使用非缩放时间，2×不缩短悬停等待；刷新上限约每秒 7 次。浮层高度随文字内容调整。

## 3. 主页历史对局

主页新增“历史对局”和“封存当前对局”。封存后该局进入历史，主页可以开始另一局，也可恢复之前的封存局。

- 历史记录展示保存时间、天数、胜场、精力、等级和状态；选择记录查看装备、背包数量、本体生命、金币和保命状态。
- 封存保存完整局内快照：物品实例、成长、冷却强化、吸收程序、药水配方、永久属性、下一场药剂预约、事件选择与怪物备选。
- 有正在进行的对局时，恢复按钮禁用；控制器同样拒绝恢复，避免仅靠 UI 检查而覆盖当前局。先封存当前局再恢复另一局。
- 失败与十胜通关自动记录。失败记录只可查看，不能复活恢复。通关记录可恢复并进入无尽。
- 同一局有稳定 RunId，封存或结束时更新该局的一条记录。继续游玩的当前存档与历史快照使用不同文件；后续正常自动存档不会改写封存快照。
- 历史位于 Unity `Application.persistentDataPath/PKBallHistory/<RunId>.json`；当前存档继续使用 `pkball-prototype-run.json`。历史文件采用原子替换写入。
- 存档格式升级为 v3，兼容 v1/v2；旧局补充稳定 ID，旧失败局进入历史。没有额外项目副本。
- 当前只允许在非战斗阶段封存。恢复的是局内阶段与构筑，不恢复某一帧的物理运动、在途弹道或战斗临时状态。

## 4. 精力、失败扣除与一次保命

精力与角色战斗生命分开。初始精力 10；野怪及匹配战败都扣除。暂定每三天上调一次，公式：

`战败扣除 = min(8, 1 + floor((天数 - 1) / 3))`

| 天数 | 扣除 |
| --- | --- |
| 1～3 | 1 |
| 4～6 | 2 |
| 7～9 | 3 |
| 10～12 | 4 |
| 13～15 | 5 |
| 16～18 | 6 |
| 19～21 | 7 |
| 22 起 | 8 |

第一次扣到 0 或以下时触发保命：精力设为 1，`LastStandUsed=true`。之后再次扣到 0 则结束本局，立即保存失败历史，不继续发放次日经济或推进事件。

回血入口 `HealEndurance` 只恢复精力并封顶 10，不改变 `LastStandUsed`；结束局无法通过该入口复活。角色战斗回血与永久生命药剂也不修改这个标记。标记写入当前存档和历史快照，读档、封存恢复均保留。只有创建全新对局才能重新获得保命机会。

主页与准备页显示精力、当前战败扣除量、保命可用/已用。
