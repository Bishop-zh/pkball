# 录屏战斗表现与信息层级

后续架构修正：飞剑每方 16 个仅为显示上限，所有逻辑剑独立保存伤害和命中节奏，不再将伤害并入代表剑。全剑齐射规则保持。本文下方的“合并贡献”是旧实现记录，当前实现和回归见 [40-状态边界与统一战斗调度](40-状态边界与统一战斗调度.md)。

## 目标

在保留统一圆球角色美术和两个模式共用逻辑的基础上，让关键装备拥有可辨认的起手、攻击和命中反馈。战斗时常态只显示正立角色；装备只在释放时或明确的持续召唤效果中出现。视觉动画与权威伤害结算分离，伤害可延迟到命中，冷却从发动时开始。

## 本轮三件装备

- 死神镰刀：扩大实际攻击距离，用巨型紫白弧形挥击展示收割；敌人最大生命的三分之一伤害及暴击规则保持。强调挥击轨迹与命中位置，不能只把静止武器贴图放大。
- 史莱姆核心：发动时绿色扩张波纹，随着本场生命成长放大角色图案。碰撞球保持原半径，视觉尺寸需设上限，避免遮住整个竞技场。战斗结束清除本场成长与表现状态。
- 青竹飞剑：发动新增飞剑，飞剑在场上持续穿刺；再次发动时已有飞剑一起攻击目标。实体表现池有限，逻辑贡献可合并处理，避免后期生成大量 GameObject 和每帧分配。

## 共用表现系统

释放动作负责音效、出现和攻击轨迹；命中动作负责冲击、状态颜色与伤害数字。表现读取实际装备实例，支持主播配置的尺寸、弹速、攻击延迟与命中特效。摄像机、UI和碰撞不能依赖某种固定角色皮肤。

持续召唤属于战斗实例状态，不写回装备永久成长。永久属性仍由数值账本保存，不由动画帧驱动。二倍速统一使用战斗时钟推进冷却、轨迹及持续攻击。对象池满只简化视觉，不能丢弃权威伤害。

## 战斗UI

左右装备栏增加宽度与格子尺寸，中间仍保留圆形竞技场的主体地位。关键数值放在每个道具格内部上沿，最多三块；只显示数字，用红/银白/绿/橙红等底色区分伤害、护盾、治疗、灼烧、中毒。毒火排序权重保持五倍，展示数值不乘排序权重。生产数量放右下角，冷却遮罩仍覆盖图标。

数字块不浮到格子外，不与图标、等级及冷却说明重叠。小元素用简洁底色，避免重复厚边框。未装备格只显示空格，不显示无意义位置编号。

## 道具详情

参考橡木塔的信息次序，保持本项目美术配色：名称与等级、稀有度、冷却与关键输出的大数字、分隔线、特殊效果、底部分类标签。装备实例只显示当前等级及已经获得的成长，不重复原始属性和完整一至四级表。完整等级表留在主播编辑器；滚轮预览时展示对应预览等级。

战斗悬停增加真实剩余冷却、本场产物与动态输出，双方都能查看。避免把来源、调试日志、所有等级的公式挤进效果说明。

## 验收

后台用 Unity Camera/Canvas/RenderTexture 检查实际布局和战斗关键帧，不抓桌面，不激活前台。检查巨型挥击、角色体型与飞剑是否可辨认；两侧数字块是否在所属格内；详情是否遮挡或裁切。机制测试检查召唤清理、视觉上限、伤害节奏和历史存档兼容。
## 本轮落地参数与检查结果

- 死神镰刀：实际攻击距离12、图像尺寸4.5、动画0.85秒；0.3秒命中延迟及1/3敌方最大生命伤害保持。月牙由三层池化轨迹组成，方向以发动时目标为准，视觉轨迹半径限制3.4避免跨越整张画面。
- 史莱姆：每次核心发动增加视觉计数，尺寸为 `1 + 1.2*(1-exp(-次数*0.12))`，逐渐接近2.2倍；不会改变球形碰撞半径或物理质量。绿色扩张环与本场成长同步，下一场重新建立角色后清零。
- 飞剑：每次召唤一把；释放会使全剑齐射，命中后2.4秒再次攻击，另加实际飞行时间。每方最多16个视觉代表，超过上限把新剑的快照贡献合并到代表剑，逻辑剑数继续增加。伤害不因减少表现实体而丢失，反应链被隔离，战斗结束回收。
- 默认飞剑尺寸0.7，默认冰霜命中特效；主播模式覆盖图标、弹体尺寸、弹速和命中特效仍有效。
- 左右面板420×900，道具格174×104。纯数字色块放格内上沿，护盾银灰底深色字，伤害红底、治疗绿底。详情显示当前等级实际成长，完整等级表留在主播编辑器。
- Unity后台编译及统一入口通过：40逻辑剑/16视觉、320合并齐射伤害、自动再攻击、史莱姆成长/物理半径分离、战斗结束回收、UI边界与富文本字形宽度。已查看正式圆盘上的镰刀、史莱姆、飞剑关键帧及详情卡。
- 关键帧和机制检查不等于录屏成片验收；完整对局的战斗节奏和镜头观感仍需实际录制时微调。本轮未改变存档格式。
