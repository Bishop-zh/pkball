# 界面与交互

目标平台首版为 PC 16:9 横屏，使用 UGUI + TextMeshPro。先保证键鼠完整流程，同时所有关键按钮可通过键盘焦点访问。Canvas 分为静态背景、准备页动态内容、战斗 HUD、浮动提示与弹窗；频繁变化的伤害数字不与整页商店共用重建区域。

## 页面流转

主菜单 → 角色/起始特性 → 日初路线选择 → 商店或事件 → 准备界面（仓库、装备环、锻体台） → 对手预览与发射 → 战斗 → 结果账本 → 若有则强化三选一 → 下一天。第 10 天或失败后进入本局总结。战斗中的背包只读，避免中途换装影响事件结算。

## 准备界面布局

```text
┌ 日期/等级/经验/金币/锻材/下次强化 ─────────────────────────────┐
│ 左：商店/事件/锻体台 │ 中：4～10 格装备环 │ 右：物品详情与数值比较 │
│ 商品/配方/针剂列表   │ 角色中央、前双格标记 │ 来源、冷却、联动、售价 │
│                     │ 邻接/对位高亮       │ 当前与放置后差额       │
├ 仓库：分类、筛选、合成预览、临时领取 ──────────────────────────┤
└ 撤销布局 / 对手预览 / 确认准备 ────────────────────────────────┘
```

拖道具时执行非破坏性预览：合法格绿色、替换格黄色、非法格红色；同时连线高亮相邻/对位效果和前格朝向。释放后用事务提交，失败则回到原位。扩格预览显示旧道具位置和新邻接关系，确认后生效，可在当天撤销一次。道具详情按“基础属性、装备位置收益、格位收益、锻体/强化修正”拆开显示。

针剂从仓库拖到中央角色锻体核心；格位铭刻片拖到格位；武器只可拖到环上的空格或交换格。出售拖到回收区或点详情里的出售按钮。合成区列出当前可用配方与欠缺材料，不要求玩家记忆隐藏配方。临时领取区物品必须处理后才可离开页面。

## 战前、战斗与结果

战前竞技场占主要面积，鼠标拖拽箭头控制方向和力度；数值栏实时显示预估初速度及质量对它的影响。对手预览展示生命、速度、体型、可见武器和大致流派。前双格朝向由明显的弧线/缺口表现，玩家能看出它们在追踪敌人。

战斗 HUD 上方是双方生命、能量和时间；左右各显示两件关键武器的冷却图标，底部可展开只读装备环与战斗日志。近战攻击时显示进入射程的扇形提示；远程锁定有短暂瞄准线。大量伤害数字在同目标短窗口内合并显示，不改变真实结算。

结果页显示胜负、按来源分组的伤害/承伤、触发次数、金币/锻材/经验流水，以及下一天可支配资源。定期强化页全屏展示三张候选，标明银/金/棱彩、当前构筑相关性、是否提升格位或锻体。活动开局双强化可连续使用同一页面，由日程规则驱动。

## 可替换原型美术

原型角色位图位于 `Assets/PKBall/Art/Prototype/character-disc-cyan.png`。作为贴图/Sprite 占位，不作为碰撞形状来源。角色视觉可先用贴图面片或简单圆柱材质；后续皮肤替换 `VisualId → Sprite/Material/Prefab/VFX/Audio` 映射即可。武器与格位图标先用简洁的程序化几何和 UGUI 色块，占位资源不得直接写进战斗规则。
