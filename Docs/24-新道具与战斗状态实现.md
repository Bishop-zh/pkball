## 2. 药水与吸收操作

- 将背包针剂拖到角色中心直接使用，或选择后点使用；不再限制同类总使用次数。
- 将针剂拖到已装备的超级注射器格子保存配方；也支持背包物品拖到背包中的注射器。
- 将装备拖到已装备的吞并齿轮格子吸收；也支持背包之间拖拽。
- 同名同等级装备优先执行合成，吸收不能吞自己。源物品在同一次操作中被移除。
- 目标等级吸收率 **10% / 20% / 50% / 100%**，吸收时锁定，之后升级不追溯放大旧配方。
- 齿轮保存供体的被动数值、主动程序、成长、分类、生产、撞击倍率与联动身份；再吸收齿轮时展平程序，不引用已销毁供体。不复制吸收入口本身。
- 同类程序按定义和原等级归并，保留触发、生产、冷却强化的尾数；原冷却强化转为齿轮每周期的执行频率收益。宗师只强化符合分类的学徒程序。

永久针剂：本体生命 +10、速度数值 +3、攻击伤害 +3%；金币药 +5 金币。金币药通过药剂事件获得。

三种生产器每 **10 / 8 / 6 / 5 秒**产一管对应永久针剂；随机药釜每 **16 / 14 / 12 / 10 秒**产一管短效药，五种等概率：下一场 +40 开场盾、+15 速度、+15% 攻击伤害、10% 直伤减免、+40 临时生命。短效药仅作用于下一场实际战斗。开战时消耗预约，战后清除，查看界面不消耗。

注射器复放永久药时再次增加本局永久属性；复放短效药时作用于当前战斗，不预订未来场次。金币保留小数信用，满一金币后进战后账本。生产不在战斗中创建背包物品实体，战后加入背包，满包进入待领取区。

## 3. 战斗状态规则

- **毒**：每 1 战斗秒造成当前毒层等量伤害，穿盾，不自然衰减。治疗不受毒素影响；实际恢复量的 10% 清除毒层，保留小数，溢出治疗不清毒。再生走同一治疗入口。
- **火**：每 0.5 战斗秒造成当前火层伤害，再衰减 `max(1, ceil(火层 × 5%))`。护盾受火伤为一半：盾消耗 `min(盾, 火伤/2)`，生命伤害 `max(0, 火伤-2×原盾)`。
- **护盾**：普通直伤和碰撞先扣盾，剩余扣生命；毒、疲劳、骤死直接扣生命。盾在战后清除。
- **再生**：每秒恢复配置值，不超过生命上限。学徒泉石增加的是本场速率，其下次输出成长保存在物品实例，二者分开。
- 同时刻先毒、后火、再治疗；死亡后不再恢复或自然激活。
- 宗师减冷却倍率 **5% / 10% / 20% / 50%**，连续乘算；加速前最低 1 秒，已有剩余冷却保留进度。游戏 2×同步加快冷却、弹道和状态跳数。

## 4. 角色与攻击表现

角色根节点保留 Rigidbody / SphereCollider，但隐藏物理球体 Renderer。角色图案挂在角色根节点，与攻击朝向分离，固定正立；图案尺寸依据碰撞直径放大并补偿透明留白。

常态不生成环绕装备图标。成功释放时才短暂显示当前武器/装置，之后收回池中；近战有刺击、横扫或重击，保留高级武器模型接口。被吸收武器也可以产生对应释放表现。

释放成功立即开始冷却并快照输出。近战约 0.14 秒后提交命中；远程按武器弹速追踪目标，激光/炮弹可分别配置快慢。目标已经死亡或整场结束时取消残余命中，不因实例后续成长改变在途攻击。

盾显示黄色壳圈，厚度随盾量增加；毒显示绿色染色；火显示小火舌；回血显示上升绿色粒子。伤害、毒、火、治疗、加盾/耗盾使用各自颜色，数字大小随数值变化。

战斗侧栏显示真实盾、毒、火、再生读数；武器就绪但近战距离不足时不提前释放。主遮罩显示主动效果冷却，绿色细条独立显示产药进度，右下角计数显示该实例本场产物数量。

## 5. 数据持久化与性能

- ScriptableObject 只保存共享配置；成长、配方、吸收、冷却强化在 ItemInstance 中，合成和场景切换保留。
- CombatState 保存毒火盾再生，不进入永久存档；临时预约另存 PendingBattleModifiers。
- 战斗时立即修改内存数值，增长账本按来源归并；每 5 秒及暂停/退出时建立检查点，战后提交生产和经济一次。
- JSON 快照在主线程构建，写盘使用每存档路径一个后台串行队列；排队旧快照可由更新快照替代，临时文件原子替换。正常退出等待写入完成。突然进程终止仍可能丢失最后一个检查点之后的增量。
- 中断后读取检查点，结算已经记录的产物和成长，不把本场临时状态变成永久，也不自动算胜场。
- 释放图像池 32 个、数字池 48 个、弹体显示最多 96 个。视觉容量满时只省略表现，真实伤害仍提交；弹体超容量保留按距离与弹速计算的延迟。
- 延迟命中使用二叉堆按命中时间和释放序号排序；到期后当前模拟步立即处理，不用视觉队列拖延数值。
- 数字按角色/类型先在 0.1 秒内归并，并在当前数字出现后的 0.65 秒窗口内累计到同一显示对象；不同类型使用错开的显示位置。数值结算不等待数字显示。无每次触发创建协程，没有每件药水一个战斗实体。
- UI 状态和产药条通过自动导入迁移写入现有战斗预制体，不重建主菜单、准备场景或另建项目。编译后在编辑模式自动执行，无需工具栏操作。

## 6. 2026-10-03 验证结果

在正式项目 `C:/code/GameMake/PKBall` 中使用 Unity 2022.3.62f3c1 完成检查。

- **脚本编译**：新代码编译通过；补齐 ItemInstance 缺失的 UnityEngine 引用。
- **数据规则**：20,158 条断言通过。覆盖新道具定义、药水使用、生命升级计算、合成成长、无限吸收、短效药预约、存档恢复与战后产物只提交一次。
- **状态计算**：验证毒伤穿盾，实际治疗量的 10% 清毒且不降低治疗；燃烧跳数、衰减与护盾减半伤害；再生不超过最大生命。
- **运行流程**：主菜单 → 准备 → 战斗 → 准备 → 主菜单通过。UGUI 射线、按钮点击、装备拖放通过，保留已编辑的场景内容。
- **战斗运行**：16 种新增定义均在编辑器战斗中执行。产药独立计时、注射器复放、吞并成长、学徒成长、宗师冷却、令牌额外激活、近战延迟命中通过。
- **二倍速**：战斗计时与剩余冷却同步；游戏状态与攻击使用同一战斗时间推进。
- **角色表现**：检查真实 Game 画面及运行对象，图案正立、不随攻击朝向旋转；根球体 Renderer 关闭，SphereCollider 保留；图案宽度覆盖碰撞直径。常态武器隐藏，释放时才启用表现。
- **界面修正**：名称与等级拆分，降低长名称字号，减少截断；浮动数值按角色与类型累计并错开位置，减少密集重复数字重叠。
- **健壮性修正**：战斗只装载已解锁格子；没有新增战斗增量时跳过检查点写盘。
- **事件队列**：10,000 条延迟攻击验证排序正确、不丢数值。此项是正确性验证，不是帧率或真实高负载基准。

规则测试的断言通过后，一次无图形批处理在 Unity 原生退出阶段停滞，已确认并结束该次测试进程；后续图形批处理的场景和战斗检查正常退出。编辑器日志另有 Android 扩展及更新检查提示，未作为本项目功能错误处理。

测试使用临时运行数据及独立临时存档，没有替换玩家正式存档。测试脚本、生成的对应 meta 和本轮测试日志验证后移除，不保留额外项目副本。

仍需后续完成：真实长局平衡、目标设备 Profiler 帧耗时与 GC、实际 SpriteAtlas 合批效果，以及大量弹体和状态同时出现时的性能测量。本次数值表仍为首轮配置。
