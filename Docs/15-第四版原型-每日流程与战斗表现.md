# 第四版原型：每日流程、野怪、格位附魔与战斗表现

## 一天的流程

每日固定经过六个阶段：事件一 → 事件二 → 野怪 → 事件三 → 事件四 → 镜像对手。每个事件从三个选项中选择一个，可能进入商店，也可能立即获得金币、金矿、矿镐、随机武器、两支针剂或格位附魔。只有选中商店事件时，商店商品与刷新按钮才可操作。选择事件后仍可整理背包，点击“前往下一阶段”推进。

野怪阶段可以在普通、精英、BOSS 三个对手中选择；选项卡显示生命、速度、撞击加成、武器倍率、当前道具与胜利金币。选定后仍可调整装备，再进入战斗。最后的镜像对手目前由 `IPrototypeOpponentProvider` 的本地实现，从当天的野怪表选择一个难度并使用玩家外观；以后可换成玩家快照或匹配服务。阶段、选择、格位效果和局内生命均随本局存档保存。

## 局内生命与通关

开局拥有 10 点局内生命。野怪和镜像对手战败都会扣除局内生命：第 1–3 天扣 1，第 4–6 天扣 2，第 7 天及以后扣 3。生命第一次将降至零时触发一次保命，回到 1 点；再次归零则本局结束。击败镜像对手才计入胜场；到达 10 胜通关，可在准备界面选择进入无尽模式。第 10 天以后继续沿用第 10 天的野怪表。每个完整日结束保底获得 12 金币，胜利再加 4 金币；附魔的富饶格位可再增加收入。

## 格位自身的成长

初始 FR 是活力格，FL 是迅捷格。事件附魔可将最近指向的开放格位改成下列一种效果；装备取下或换位时，效果留在格位上。所有效果只在格位装有道具时生效。

| 格位效果 | 对该格道具的作用 |
| --- | --- |
| 活力 | 生命 +8，且该道具的生命属性额外 +20% |
| 迅捷 | 速度 +4，且该道具的速度属性额外 +20% |
| 锋利 | 武器直接伤害 +20% |
| 回响 | 武器冷却缩短 15% |
| 守护 | 撞击减伤 +5% |
| 富饶 | 完整日结束额外 +2 金币 |

格位颜色区分效果，指向格位可查看说明。属性始终由基础值、永久修正、装备实例与格位效果重新计算，避免换位后增益残留。

## 武器表现、二倍速与美术

原型移除了角色两侧的长方形挂件，装备在角色周围显示透明 PNG。`Assets/PKBall/Art/Generated` 保留两张 4×4 统一风格图集，`Resources/Icons` 保存切出的独立透明 PNG。UI 和战斗场景都通过道具的 `iconId` 读取图标。指向道具并滚动鼠标滚轮可预览 1–4 级数值。

近战按碰撞外沿距离和面向角判定：矛、戟是较窄的前向穿刺；剑是较宽的挥砍；锤、矿镐是重击。每次命中会播放短促的图标位移动画，并按武器配置的方向与冲量击退敌人。撞墙后的方向加入交替切向偏移，降低双方一直在同一水平线上往返的概率。战斗底部按钮可切换 1×/2×；角色物理、武器冷却、Buff 时长与战斗计时都使用游戏时间，因此一起加速。上方血量和能量条改由矩形宽度直接更新。

`PrototypeWeaponDefinition` 已预留普通 `modelPrefab`、四级 `legendaryModelPrefab` 和模型缩放。若模型未赋值，继续显示 PNG；赋值后在相同装备格位实例化 3D 模型，并禁用模型自带碰撞器，战斗命中仍由武器数据决定。第 7 天后商店可出现巨刃、破阵戟、电弧炮、斥力锤，这四件高级武器目前有独立 PNG 作为模型到位前的回退表现。

## 仍需调校

当前镜像对手使用本地替身，尚未接入真实玩家构筑和匹配。野怪的道具只计算已接入的生命、速度、撞击和武器效果；其余道具特效还需与统一事件系统连接。图集切图、规则检查与无图形自动战斗可自动验证，UGUI 拖拽和角色画面的手感仍需要在编辑器或 Windows 构建中人工试玩调校。
