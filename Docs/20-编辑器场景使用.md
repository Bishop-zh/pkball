# 在 Unity 编辑器中直接使用游戏

打开 Unity Hub 中的 PKBall 项目。主菜单场景已经保存，进入编辑器后切到 Game 标签即可看到主菜单；点击顶部三角形 Play，再点击「匹配模式」开始或继续游戏。不需要点击任何 PKBall 生成工具。

## 场景与切换

- `Assets/PKBall/Scenes/MainMenu.unity`：主菜单入口，可在非运行状态查看标题、匹配入口、角色外观和旅程档案。
- `Assets/PKBall/Scenes/Preparation.unity`：事件选择、商店、背包、装备圆环、角色数值、野怪选择与情报。根据当天阶段显示对应面板。
- `Assets/PKBall/Scenes/PrototypeBattle.unity`：战斗场地、摄像机、灯光、角色示例、瞄准线和战斗 HUD。

主菜单 → 准备 → 战斗 → 准备，准备页「返回主菜单」回到入口。局内数据由同一份 Run 保留，场景对象随场景释放。战斗结算后自动回到准备阶段。

Play 默认从 MainMenu 开始，避免从编辑中的战斗页进入不完整的流程。模板 SampleScene 也已换成完整的主菜单内容。

## 直接调整界面

在 Hierarchy 展开 `PKBall_GameRoot`。`MainMenuUI`、`PreparationUI`、`PrototypeHUD` 下有保存好的 Canvas 和真实 UI 元素。界面布局可直接调整 RectTransform，图片可替换 Image 的 Sprite。当前阶段未显示的面板会处于关闭状态，也会保留在层级中。

`Assets/PKBall/Prefabs/Screens` 保存三个场景的完整根 Prefab；`Assets/PKBall/Prefabs/Actors/Combatant.prefab` 是战斗角色的生成模板。双击 Prefab 可编辑，再保存。场景中对 Prefab 的修改也可通过 Inspector 的 Overrides 应用回 Prefab。

角色初始展示、场地、墙体、灯光、摄像机和 UI 都已经保存。运行时仍会按当前背包与对手数据生成实际战斗角色、装备外观、投射物，并更新 UI 文本和显隐状态；不重新创建已保存的 UI 布局。

## 数据与资源

- 道具与数值：`Assets/PKBall/Resources/Items`、`Weapons`、`PrototypeBalance.asset`。
- 角色图片：`Assets/PKBall/Resources/Art` 与 `Visuals`。
- 保存后的 UI Sprite：`Assets/PKBall/Art/SceneSprites`。
- 场景材质：`Assets/PKBall/Art/SceneMaterials`。

场景已经加入构建列表，MainMenu 为第一场景。保存场景即可打包，不需要先运行生成工具。
