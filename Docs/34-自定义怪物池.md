# 自定义怪物池

主播编辑器可将当前角色加入普通、稀有、BOSS三类怪物池。保存角色独立副本；同名且同类别更新原ID，其他类别互不覆盖。基准天数范围1～10000。

数据存于 persistentDataPath/monster-pool/{id}.json。每次写临时文件后原子替换，旧版保留 .bak；损坏的单个条目跳过，其余正常使用。缓存只在保存或 Reset 后刷新，外部文件变化不会影响当前候选。当天抽取结果由跑局存档保存。

PrototypeMonsterPool.All(tier)、Count(tier)、Find(id) 提供池查询，Save(side,tier,referenceDay) 导入角色。查询及 ScaleToDay 返回独立副本，战斗不会修改池中模板。SetDirectoryForTests 可临时替换目录，传 null 回到用户目录。

默认每天生命成长12%，输出成长8%。以基准天数为起点，倍率为 (1+成长率)^(当前天数-基准天数)，限制0.05～1000。角色白板生命、装备生命及吸收生命按生命倍率增加；初始护盾按输出倍率增加。武器伤害及伤害、盾、治疗、毒、火、再生词条的实际值（含成长记录）由战斗输出倍率统一增加。百分比、持续时间、冷却、冷却缩减和触发数量保持原规则，增伤比例不会重复放大。吸收针剂的生命和初始护盾分别使用对应倍率。

内部 monsterHealthScale / monsterOutputScale 参数只用于怪物构建，不增加用户JSON配置界面。

## 使用方法

1. 主页进入主播模式，选择红方或蓝方，配置角色姓名、图像、装备和词条；也可先读取角色预设。
2. 点击角色区下方“加入怪物池”，选择普通、稀有或BOSS，并填写基准天数，确认加入。
3. 基准当天使用配置的原始强度。例：基准第5天、白板生命500，第6天白板生命560；固定数值输出为基准的1.08倍，第4天则为1/1.08。装备生命同步按生命倍率缩放。
4. 新对局开始或进入新一天时，三个类别分别从内置及导入候选中均匀随机抽取一个。已有当天候选保持不变；同名同类别更新将用于以后抽取。

暂时沿用内置怪物作为基础池。内置和导入怪物的身份、装备组合均不按天数替换，天数只调整数值；内置怪物10天后继续使用同一身份和装备。排位当前的镜像替身接口复用该池，后续可接真人对手。

## 存档与性能

跑局存档升级至v7，兼容v1～v6。保存每类候选的稳定ID和导入配置快照，修改、删除、重排外部池不改变已抽中的当天怪物。装备格保留空位，预览索引与实际装备位置一致。

缓存池数据，按来源快照及天数缓存当天缩放角色。实际战斗通过共用主播装备构建入口生成独立实例；生命、输出倍率仅作用于怪物实例，不写回道具目录、主播预设或玩家永久成长。生成的运行时资源随战斗释放。
