# 全道具特色动画与主播编辑

目前全部 73 件道具均配置独立动画。JSON 为可调数据源，Items 下 ScriptableObject 保存同值后备配置。JSON 每条 item 使用 animationSchemaVersion=1 明确标识动画数据。旧 JSON 缺少标识时回退同 ID 资产（Unity JsonUtility 可能为缺失字段创建空嵌套对象，不能仅判断 null）；标识为 1 的 Auto 自定义参数完整保留。animation 为 null 时也保留同 ID 资产配置；完全缺省交由 Auto 按原道具识别。

动画仅呈现真实发生的事件，不添加伤害、治疗、护盾或资源。无主动释放的装备使用开战、实际触发、生产、吸收、准备阶段使用等事件表现。针剂只在准备阶段使用时播放；材料在获得/合成时反馈。不能仅为播放效果增加假释放。

主播模式在每道具编辑其动画样式、颜色、时长、尺寸、强度、数量、图标开关与旋转。None 禁用该道具动画；Auto 使用识别结果；选择明确样式应尊重编辑值。战斗数字、既有武器命中与持续飞剑伤害独立于此动画。

参数：preset 选择形态；tint 为 RGBA；duration 为秒；scale 控制范围/图标尺寸；intensity 控制亮度/振幅；count 控制装饰元素数量（不增加攻击次数）；showIcon 控制道具图标；rotation 为角度。持续飞剑、死神月牙、史莱姆成长保持其原有机制，额外表现受同一配置控制。

生产器呈现药液气泡，矿镐/金矿呈现金粒，吸收器呈现汇聚旋涡，疾风轮呈现环绕疾风，突破核心呈现核光环。所有默认参数为轻微差异以方便辨识。

## 主播编辑操作

选中装备格后打开右侧“道具动画”页。开启自定义后，可选择动画样式，调整时长、尺寸、强度、装饰数量、旋转和图标显示；向下滚动可调整 RGB 颜色。默认值直接显示，“恢复默认”重新继承道具配置。保存角色或对战预设时一并保存动画设置，两个模式共用同一套表现系统。

旧角色、旧对战预设及怪物导入配置通过动画版本标识区分“继承默认”和“明确覆盖”。旧数据缺少标识时继承默认，不把 Unity 自动生成的空对象误当成自定义。明确选择 Auto 时仍保留其他自定义参数。

## 触发与性能

战斗动画由实际释放、响应词条、生产及被动装备碰撞事件触发。准备阶段在获得道具、使用针剂、出售、合成、吸收和突破成功时播放图标反馈。材料不会被添加虚构的战斗攻击或冷却。

战斗装饰复用 32 个表现对象，准备界面复用 8 个图标对象。装饰数量不改变攻击次数；表现池容量限制只影响装饰，不丢弃游戏数值事件。持续飞剑与史莱姆成长仍由各自的战斗机制驱动。
