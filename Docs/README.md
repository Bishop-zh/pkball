## 项目定位

PKBall 是单角色弹射决斗与圆环装备构筑结合的 Roguelike 增量游戏。每局按天推进：经营、选事件、购物与锻体、布置装备环、瞄准弹射、自动战斗、结算。胜负以生命值为准。不制作角色主动技能按钮；武器、道具、格位与强化可自动触发效果。

## 已定原则

- 战斗为平面运动、URP 三维表现。首版两个主角实体各有一个连续碰撞体；装备格位是角色周围的部件与命中区域。
- 标准装备环从 4 格成长为 6、8、10 格。前方双格由稳定槽位 ID 表示，扩格时不改变已装备道具的槽位 ID。12 格只作为未来特殊活动的规则覆盖。
- 生命上限影响质量与速度，不把当前掉血直接映射成质量，避免受伤后突然加速。
- 原型先使用简单模型与位图占位；渲染资源引用经过表现层配置，日后可换皮肤而不改战斗数据。
- 所有价格、公式和掉落权重通过配置维护。下文数值用于做第一轮可玩性实验，并非承诺的最终平衡。
