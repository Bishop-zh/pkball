# 第三版原型：道具实例、合成、针剂与外观

> 此文记录第三版实现。当前每日事件、野怪选择、格位附魔、局内生命与图集以《15-第四版原型-每日流程与战斗表现.md》为准。

## 启动与操作

打开 `Assets/PKBall/Scenes/PrototypeBattle.unity` 进入 Play，或运行 `Builds/Prototype/PKBall.exe`。首次本局从第 1 天、24 金币、4 格、无流派加成和无装备开始。首日商店前三项固定为冲刺矛、追踪弩、生命培育舱；第 4 项随机。每场结束固定获得 12 金币，胜利另外奖励 4 金币。

- 点击商品购买，或把商店商品直接拖到背包格或开放的装备格：拖到装备格会一次完成购买与装备；若该格已有同名一级物品，会直接合成二级，否则旧物品进入背包。商店装备均为 1 级，同名同级的两件可合成：先点击背包中的主件，再点击副件，或把一件拖到另一件上。把背包中的同名同级装备拖到已装备格位上，也能原位合成。`1+1→2`，`2+2→3`；直接武器伤害随等级为 1/2/4 倍。
- 选中背包物品后点击格位装备，或从背包拖到任意开放格；点击已装备格位卸下。武器不限制格位，也可以安装多把同类武器，每把独立冷却、参与战斗。近战只有贴近目标、处于正面挥击角度时才可命中，距离按角色碰撞外沿计算，约 0.3–0.4 世界单位，与视觉武器伸出距离接近。把吞并齿轮装在格位后，可将另一件一级装备拖到它上面，每天吞并一次，增长齿轮实例的撞击加成；卸下齿轮后该成长不加到角色，重新装备又恢复。
- 针剂可拖到装备环中央的角色图上，或选中后点击“给角色使用所选针剂”。基础生命、力量、迅捷针剂分别提高本局生命、撞击加成、速度。使用后针剂消耗，不占格；右侧“角色数值”可查看当前属性及来源。本局永久加成在场景重建和退出后重开程序时保留。
- 获得三级装备并达到较高经验后，商店可能出现突破核心。选中/拖动突破核心到三级装备格位，可升为四级，并一次性获得本局生命 +10。商店不会常规售卖二三级装备。
- 矿镐近战每两次有效命中累计一块金矿，单场按等级限量。战后金矿进入背包资源计数；在商店下方点击“出售背包中的金矿”换取金币。
- 商店不直接出售针剂。装备生命培育舱、力量蒸馏器或迅捷离心机后，会在每回合结束时累计生产进度：一级每两回合生产一支，同等级叠加可提速。产物先进入待领取区，点击装备盘下方“领取生产的针剂”放入背包；背包满时不会丢失，退出后也会随本局存档保留。新增轻剑、重锤、防壁、推进器等道具。
- 点击“进入战斗”后在场地内拖动鼠标发射；战斗结算后进入下一天。R 重建当前战斗场景；“新的一局”从白板重开并覆盖本局存档。

## 表现与数据

玩家、敌方玩家、怪物各有一张独立的纯色块 PNG 和 SVG 源图。角色图由 `Resources/Visuals` 下的 `PrototypeVisualDefinition` 指向，当前每第三天显示怪物外观。已装备道具在角色周围使用对应图标表示；前方武器和装备环随敌人方向转动。更换定义中的贴图不会修改物理碰撞与战斗数值。

静态道具定义仍在 `Resources/Items`；购买后生成拥有独立 ID 和等级的 `PrototypeItemInstance`。`PrototypeStatCalculator` 从白板基础值、本局永久修正、已装备实例重新计算属性，卸装和换位不会靠反向减法“猜”回原值。`PrototypeBuffManager` 以来源键维护本场限时 Buff；当前示例为疾风轮相邻冲刺矛时，近战命中刷新 2 秒速度 +4。针剂、合成等级、吞并成长、金币和格位写入 `Application.persistentDataPath/pkball-prototype-run.json`。无图形自动测试使用独立的临时状态，不覆盖玩家存档。

## 已验证与下一步

Unity 批处理成功导入、编译并构建 Windows 可执行文件。编辑器规则检查覆盖 1+1→2、2+2→3、针剂、吞并、Buff 刷新与到期、永久修正存档重载；无图形自动战斗可以进入结算且没有脚本异常。

这仍是逐步扩展的原型。完整的道具效果声明式配置、全部相邻/对位能力、商店事件、四级专属效果、战斗中途存档与高负载事件调度尚未接入。当前战斗的伤害即时结算、弹丸对象池和矿石整数账本为后续事件系统提供基础；下一阶段应先把战斗触发器与按来源的结果账本整合，再扩内容，避免新道具直接散落在 `PrototypeActor` 和 `PrototypeRun` 的条件判断里。
