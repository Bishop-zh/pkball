# 词条与 Buff 架构

装备定义保存稳定的基础属性与 effects[] 词条。每条包含类型、基础量、每次释放成长、匹配标签、暴击概率与倍率。主播配置用 overridesEffects 区分继承默认与覆盖：false 继承目录，true 使用 effectsOverride，空数组明确关闭全部词条。保留旧版毒、火、护盾等覆盖字段，旧预设仍可读取。定义不承担运行时堆层状态。

装备实例持有永久修正账本。每次激活按当时等级算出实际增量，再将实际数值累加至来源与稳定词条 ID 对应记录；例如一级释放两次共 +4 伤害，升至二级仍为 +4，后续激活才使用二级增量。相同来源的层数与数值聚合，不为每层创建对象。升级改变基础属性，不重新计算历史成长。冷却修正使用同一账本，乘法冷却可累积对数，从而支持来源合并与快照。

战斗人物保存白板生命与基础属性，另持战斗 Buff 集合。每次史莱姆凝胶释放增加一层本场最大生命 +5% Buff，按触发时当前最大生命计算实际增量，累计到账本，连续八次上限乘以 1.05^8。结束战斗清理本场记录，永久装备账本继续保留。中毒、灼烧、再生由状态 Buff 按类型聚合，CombatState负责定时结算、衰减与治疗清毒；普通属性Buff按来源聚合并支持到期移除。两类记录均限定于本场战斗，伤害和治疗结算仍通过人物的统一入口。

性能成本与不同来源/词条记录数量相关，与累计释放次数无关。事件发生时更新缓存，战斗状态按统一 tick 调度，不为每层 Buff 创建 GameObject、MonoBehaviour 或独立 Update。UI 仅在值改变时刷新，顶部前三项排序至多遍历装备词条并维护三个候选值，毒/火权重为普通即时数值的 5 倍；治疗、盾和再生保持权重 1。

旧档只保存成长累计值，缺乏历史等级，无法还原每次释放的真实增量。加载时按旧档现有结果进行一次迁移并记录完成标记，此后全部使用快照增量。主播的初始叠层作为当前设定等级的模拟历史释放次数，开战前直接转换为账本，不在战斗中逐次重放。

主播编辑器提供所有十五类词条的增删与参数修改，预览使用 CreateItem 构造的实际实例。百分比、秒、每秒单位明确显示，特殊词条直接展示完整语义。首领装备通过 ResolveLevel 强制四级，编辑器等级选项随之锁定。


## 首领装备与数值显示

死神镰刀定位首领装备，固定四级；死神披风改为野外普通装备，可合成和突破，不出现在商店、普通事件、合成升级中，只能通过野怪获胜掉落。主模式与主播模式共享定义，主播可以直接配置首领装备。镰刀维持敌人最大生命值1/3伤害和20%双倍暴击，披风维持1秒无敌与7秒冷却。

战斗装备格的上沿使用轻量数值条，伤害红色、盾银白、治疗绿色、灼烧橙红、中毒绿色、再生暖黄色，并配单字标记。取实际输出按权重降序显示前三项，毒/火权重5，其余1；显示原始数值而非加权值。UI每0.1秒刷新数值，只有文本改变才更新Text。基础生命以浅白段显示，战斗Buff生命使用原阵营色段，延迟受伤条继续保留。

## 配置与参数规则

词条稳定ID在默认转自定义时保留；新增词条使用新ID，切换类型建立新ID。冷却缩减/激发学徒的amount为0时沿用旧等级策略，大于0时执行自定义比例/数量。暴击仅作用于直接伤害、敌人最大生命伤害、自身最大生命伤害词条。原JSON未提供覆盖词条时继续继承目录定义；显式空数组关闭全部词条。

## 后台回归记录（2026-10-06）

使用原项目 Unity 2022.3.62f3c1 batchmode，不激活前台窗口。编译及实际入口断言通过：

- 首领固定四级，商店、普通奖励、生产路径拒绝首领装备；野怪掉落允许获取。
- 一级实际成长 +4 在升级后二级仍为 +4；未来触发按新等级追加，合成保留累计增量。
- 稳定词条 ID 在调序、删除其他词条时保留对应成长。冷却账本、吸收账本通过真实 v6 ExportSnapshot/ImportSnapshot 恢复；v5 迁移只执行一次。
- 吸收比例伤害和无敌时长，基础效果乘吸收贡献，历史成长已经缩放，避免重复缩小；数值预览和执行计算同步。
- 旧怪物索引与追加死神/史莱姆候选保持一致；八件粘液每件先成长生命再快照 5% 伤害，战斗属性保持临时。
- UI 28 项断言通过，包含十三类词条实际输入回调、默认数值预览、前三数值排序、毒火权重、颜色和射线不拦截、基础生命段。

Unity 使用 Canvas/Camera/RenderTexture 离屏生成主播配置图，已检查八格装备区、属性分页、音效和角色区的布局；该检查不涉及桌面截图，也不等于完整连续对局的人工验收。临时测试脚本、结果、图片在检查后删除。
## 六角色扩充：触发词条与等级表（2026-10-06）

- 获取来源 acquisition（商店/野外）与 rarity、bossItem 分离；旧 bossExclusive 仅用于兼容。新怪物各一件固定四级首领物品、一件可升级野外装备，其余使用商店物品。完整等级表见 35-六角色与装备池.md。
- 词条支持 Release、Hit、BurningHit、ShieldBroken。反应触发使用独立 triggerCooldown，普通释放使用装备冷却；破盾只在护盾从正数变为零时触发。
- levelAmounts 与 levelGrowthAmounts 是可选的四级绝对值数组。不填写继续原有规则；填写后直接读取当前等级值，避免第四级效果只能按翻倍成长。
- 新词条 ConsumeShieldDamage 消耗实际护盾并追加等量伤害；TriggerTaggedEquipment 按标签激发其他装备。比例、持续时间及激发数量不乘普通输出倍率。
- 永久成长账本记录每次实际增加量，升级不重新放大过去的层数。新增等级只影响之后的触发；吸收贡献只缩放一次。
- 同步标签链用集合阻止循环，反应产生的弹体携带 suppressHitTriggers，阻止跨帧命中重新启动反应链。普通释放的攻击仍可正常触发命中词条。
- 主播编辑器可查看并修改触发条件、间隔、四级数值和成长表，预览使用实际实例。旧效果枚举 0～12 保持编号，新效果追加 13～14。
- 原项目后台 Unity 回归通过 147 项断言，覆盖获取路径、首领等级、历史成长、护盾消耗、反应间隔、标签循环及实际编辑器字段。已检查 Unity 离屏生成的词条页布局；不等于完整连续对局的平衡验收。
