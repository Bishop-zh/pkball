# 道具与流派设计：位置协同、动态成长和合成

状态：下一阶段内容设计，数值为测试起点。当前第二版原型中的 8 件道具尚未按本文实现。规则实现与保存边界见 `13-数值Buff与事件架构.md`。

## 1. 参考机制与本项目取舍

《背包乱斗》官方介绍明确把购买、摆放与合成作为构筑核心；《大巴扎》官方介绍强调不同英雄的道具集合、商人事件与单核心/连锁构筑。《橡木塔》的官方公告展示了“触发右侧另一件同类型物品”、开战触发、永久提高某项道具数值、药剂升级道具等机制，也记录了无限触发与冷却缩短造成的平衡问题。PKBall 借鉴的是**位置、时机和成长作用域**这三类设计工具；下表的道具名称、具体数值、合成和四级突破都是本项目原创提案，不对应原作物品。

参考：[背包乱斗 Steam 页面](https://store.steampowered.com/app/2427700/Backpack_Battles/)、[大巴扎 Steam 页面](https://store.steampowered.com/app/1617400/The_Bazaar/)、[橡木塔官方更新与道具例子](https://steamcommunity.com/app/3400960/announcements/)。

## 2. 合成和升级的确定规则

商店直接售卖的常规装备均为 **1 级**。同一 `definitionId`、同一等级的两个独立实例可合成：`1+1→2`、`2+2→3`，所以一件 3 级需要四件 1 级。合成保留玩家指定的主件实例 ID 与槽位，消耗副件实例；主件已有的实例成长、来源和改造遵循各字段的合成规则，不能默默消失。4 级由 3 级加“突破核心”得到，不能靠普通同名合成。道具品质（普通/稀有等）与等级（1～4）相互独立。药剂、矿石、突破核心属于消耗品/材料，不自动进入装备合成。

### 倍率约束

| 数值类别 | 1/2/3 级默认 | 为什么 |
| --- | --- | --- |
| 武器单次直接伤害 | `D / 2D / 4D` | 四件一级道具压缩为一个格位，给出明确回报；仍受冷却、射程与命中条件约束 |
| 静态固定属性，如 +生命、+速度 | 默认 `X / 2X / 4X`，逐件可覆写 | 便于玩家理解投入；百分比属性仍受总上限约束 |
| 次要效果的强度，如一次护盾量、一次充能量 | 优先 `X / 1.5X / 2.25X`，按规则统一取整 | 保留升级感，防止连锁效果和直接伤害相乘过快 |
| 资源产出与永久成长 | 单独效果表与每日/每场上限 | 不能只靠倍数控制跨战斗滚雪球 |
| 冷却、触发频率、连锁次数、目标数、持续时间、触发概率 | 不套用翻倍模板 | 这些维度与伤害/效果强度相乘，可造成远超四倍的结果 |

武器的附加特效可以按每级 `×1.5` 或 `×2`，但每件道具只选择一个“主要放大维度”，并写在等级效果表中。例如矛的直接伤害 `8/16/32`，额外撞击倍率可以是 `+10%/+15%/+22.5%`；不再同时缩短冷却。追踪弩直接伤害 `7/14/28`，保留 4.2 秒冷却和一发弹丸；命中可靠使它的基础伤害需低于同价近战武器。数值面板分别展示基础值、实例永久成长、位置修正与战斗 Buff。

由于现行原型只有 **FR/FL 两个可装备武器的前格**，四件一级武器不能同时出战。三级武器把四份购买投入浓缩成一个格位，战力跃迁会比“四件都能出战”的模型大。直接伤害 1/2/4 按需求保留，但应通过价格、四份复制品的取得时间、恒定冷却和敌人逐日成长来平衡；模拟时必须以“两个一级武器”和“一个三级武器加一个空前格/其他武器”对比，而不是假设四个一级武器都能装备。

**需要数值验证的风险**：若伤害翻倍的同时给相邻武器 `+100% 伤害`，三级组合可能瞬间终结战斗；若 `+1 次额外触发` 再复制该触发器，事件量可能指数增长。因此相邻加伤优先加法同组叠加，额外触发有每秒预算，不能触发自身，也不能在同一事件链中再次复制同一来源。所有 1/2/3 级效果表在内容检视器里显示预计 DPS、每场资源上限与事件预算。

## 3. 空间关系与生效时机

装备环的关系计算使用稳定槽位 ID 与当前 4/6/8/10 格顺时针拓扑。`Adjacent` 是左右直接相邻，`Opposite` 是相隔当前格数一半，`Front` 是 FR/FL，`Back` 是远离前向的格。扩格改变相邻/对位，准备界面必须预览加成增减。查找关系在布置、扩格或合成后重算一次，战斗中使用缓存，避免每条攻击事件遍历整个环。

### 值得借鉴的设计模式

| 模式 | 参考中可见的玩法方向 | PKBall 的对应实现 |
| --- | --- | --- |
| 位置触发另一个物品 | 《橡木塔》官方更新出现“触发右侧另一件同类型物品”的描述 | 前格、相邻、对位以拓扑查询表达；额外触发不得回指自身 |
| 开战赋予状态与战斗内滚动增强 | 《橡木塔》官方更新展示开战触发、每次触发获得奖励的道具 | 盾牌开战给本场护盾、轮胎命中刷新短加速；战后清除 |
| 道具自身永久成长 | 《橡木塔》官方更新展示逐次提高道具伤害的效果 | 齿轮吞并后写入该道具实例成长，角色不会凭空继承 |
| 药剂改造与升级 | 《橡木塔》官方更新包含升级物品的药剂 | 针剂拖到角色给本局永久属性；突破核心拖到三级道具升四级，作用目标区分明确 |
| 摆放和合成的双重收益 | 《背包乱斗》官方介绍强调摆放与合成；《大巴扎》强调商人事件和组合 | 同名合成与环形关系叠加，但每类收益有独立上限与来源明细 |

以上是机制归纳和本项目的改写，不把“对位”“吞并”“矿镐产矿”等本文提案说成参考游戏的具体原版道具。

| 时机 | 典型效果 | 存活范围 | 触发与失效 |
| --- | --- | --- | --- |
| 装备/换位时 | 相邻盾牌提供减伤、对位轮胎加速 | 装备仍满足位置时 | 更换位置立即重新计算；不能写入永久账本 |
| 战斗开始 | 前方武器获得本场弹速、护盾 | 仅本场 | 每场创建新 Buff，战斗结束清空 |
| 战斗命中/撞击时 | 临时增伤、充能、产矿计数 | Buff 或待结算战利品 | 本固定模拟步处理，不等 0.2 秒窗口 |
| 商店购买/出售时 | 提高主件实例伤害、返金、获得素材 | 道具实例或本局账本 | 交易提交后执行一次；重新刷新 UI 快照 |
| 战后结算时 | 针剂/矿石入账、满足条件后永久成长 | 本局角色或道具实例 | 同一场战斗结算 ID 只能提交一次 |
| 吞并道具时 | 消耗副件，将价值变为主件成长 | 主件实例 | 原子交易：扣除副件与写入成长同时成功 |

术语必须写进道具描述：**“本场”**随战斗清空，**“持有期间”**随装备或位置变化而增减，**“本局永久”**进入角色或道具的持久账本。道具自身永久成长随道具实例走；角色永久成长即使卖掉来源道具也继续生效，除非效果文字明确声明不同规则。

## 4. 第一批可实现道具

以下数值刻意保持效果类别简单，先测试系统和构筑，再扩内容。价格为 1 级商店价；2/3 级通过合成取得。`L1/L2/L3` 依次表示等级。每件都标明位置、时机与成长归属。

| 道具 | 价格/标签 | 等级效果与位置 | 成长归属/限制 |
| --- | --- | --- | --- |
| **冲刺矛** | 10，近战/冲撞 | 直接伤害 `8/16/32`；朝向覆盖时额外撞击加成 `10/15/22.5%`；相邻轮胎时本场撞击加成再 +5%，只加一次 | 武器基础值；相邻为可撤销位置修正 |
| **追踪弩** | 11，远程/机械 | 直接伤害 `7/14/28`，冷却 4.2 秒；对位测距仪时本场第一发额外 +10% 伤害 | 一发一目标，不放大命中次数 |
| **矿镐** | 11，近战/经济 | 直接伤害 `5/10/20`；每 2 次有效近战命中产生 1 金矿；每场产矿上限 `2/3/5`，4 级单独配置 | 金矿进战后账本；每块暂卖 2 金币 |
| **护身盾** | 12，护甲/守护 | 固定生命 `+12/+24/+48`；相邻一件武器时，开战获 `8/12/18` 护盾；对位矿镐时只显示联动提示，不额外产矿 | 生命为装备被动，护盾仅本场 |
| **疾风轮** | 10，速度/机械 | 速度数值 `+8/+16/+32`；相邻近战武器命中后，获得 2 秒 `+4/+6/+9` 临时速度，同来源刷新持续时间 | 位置关系 + 战斗 Buff，有速度总上限 |
| **缓冲护垫** | 10，防撞 | 受撞击伤害降低 `6/12/24%`；对位盾牌时减伤再 +3%，总减伤受硬上限约束 | 仅装备期间；卸下立即还原 |
| **实验匣** | 14，锻体/经济 | 每两天结算时生成基础针剂 `1/1/2` 支；若相邻矿镐，每场首次产矿后追加 1 点药剂制作进度 | 结算账本；每天最多触发一次 |
| **咬合齿轮** | 13，吞并/机械 | 在商店阶段吞并背包中的 1 级普通装备，永久给本实例 `+1/+1.5/+2.25` 点武器基础伤害，按规则取整；每日至多一次，每局累计上限 8/12/18 | 增长写入齿轮实例，卖出后消失；被吞道具不得是已装备/锁定物品 |
| **集市账本** | 12，商店/经济 | 本日第一次出售材料时额外获得 `1/2/4` 金币；对位实验匣时基础针剂购买价格减少 1 金币，不低于 3 金币 | 交易 ID 去重，出售返金有每日上限；位置折扣实时撤销 |
| **共振徽章** | 15，收藏/格位 | 相邻两件不同标签道具时，开战向这两件各赋予 `+4/+6/+9%` 本场效果强度；对位另一枚徽章时只触发一次联动 | 共享效果预算；不能自我复制或连环递归 |

4 级不使用统一 `×8`：为每件写专属变化，例如矿镐上限 8 且突破瞬间给角色本局永久 `+2%` 近战伤害；疾风轮将短加速扩展给对位格，但不增加自身重复触发频率。突破奖励由 `grantId` 记录，一次性提交；事件和商店不能把同一主件重复突破。

## 5. 五条流派及其对抗关系

| 流派 | 关键搭配 | 战斗收益 | 局内成长 | 明显弱点 |
| --- | --- | --- | --- | --- |
| **重体反撞** | 盾牌＋护垫＋冲刺矛，针剂投生命 | 生命与减伤争取更多碰撞次数 | 生命针剂、盾牌合成 | 质量降低速度，缺少轮胎时难追击 |
| **疾速穿刺** | 轮胎相邻冲刺矛，补护垫 | 高速接敌、短时速度 Buff | 升矛优先，迅捷针剂少量补足 | 被追踪远程稳定消耗；撞击承伤高 |
| **远程工坊** | 追踪弩对位测距仪，盾牌保护 | 稳定但慢节奏的远程输出 | 合成弩、买装填与护盾 | 前期需要时间开火，遭近身时弱 |
| **矿工锻体** | 矿镐相邻实验匣，集市账本售矿 | 弱于同价纯输出武器 | 战后矿石变现金与针剂 | 短战斗收入少，依赖命中次数 |
| **吞并收藏** | 咬合齿轮＋共振徽章，若干低价素材 | 位置联动提供少量本场增益 | 吞并积累单件实例属性，提升合成价值 | 花费背包材料；卖出核心道具即失去实例成长 |

初版每条路线只制作 2～3 件，保留跨路线联动。特别避免“经济道具一边无限赚钱一边成为最强战斗件”。生成材料、针剂和出售返金通过待结算账本实现，不在战斗中实例化大量 GameObject。

## 6. 平衡测试与内容验收

- 固定四份一级武器的投入，对比“两个一级武器占满前格”与“一件三级武器占一个前格”：三级直接伤害可能压过两个一级，须通过获得时间、售价、冷却、对手成长与可选第二把武器测试；绝不能把前格限制从模拟中省略。
- 用 10 天模拟记录各流派的购买力、合成完成天数、DPS、承伤、针剂累计、矿石收入与单战事件量；第 8 天 3 级核心道具应强，但不自动获胜。
- 每件道具至少有一个可显示的触发计数或数值来源；相邻/对位变化可在准备界面预览。商店、战斗和战后都能追查收益来源。
- 检查 4→6→8→10 扩格、吞并后合成、背包满时产物入账、重复结算、事件链自触发与多件同名折扣。数值与状态验证通过后再扩大物品池。
