# M0 战斗原型使用说明

## 打开与操作

打开 `Assets/PKBall/Scenes/PrototypeBattle.unity`，按 Play。鼠标在场地拖动以设置方向和力度，松开后双方发射。远程武器自动瞄准；近战进入距离和角度后自动攻击。底部按钮切换“疾速/重甲”构筑并重开，`R` 直接重开。上方显示生命、能量、有效质量、目标速度、撞击次数和时间。

若场景尚未生成，可从 Unity 菜单执行 `PKBall > 创建或更新战斗原型场景`。该操作会生成场景、`PrototypeBalance` 和四个可编辑的武器 ScriptableObject，并将原型场景放在 Build Settings 第一位。再次执行会重建场景，但不会覆盖已经存在的数值资产。

## 当前实现

- URP 三维场地、两个刚体角色、墙壁反弹、战前弹射。
- 玩家有疾速与重甲两套对照数值；敌方使用相反构筑。
- 最大生命决定有效质量，速度属性与质量共同决定目标移动速度。
- 双方块体碰撞按法线相对速度结算，有 0.25 秒同对保护；前方冲撞近战可放大对应方向的撞击伤害，护垫数值降低自身撞击承伤。
- 前方双格持续朝敌人转向；近战只在范围、角度与视线条件满足时出手；远程冷却较长，冷却就绪时朝敌人当前位置发射可躲闪的直线投射物。
- 能量移动消耗、零能量移动失血、45 秒后终局压力、90 秒强制结束。
- 投射物对象池；角色原型位图从 `Resources/Art/character-disc-cyan.png` 加载，渲染资源与碰撞规则分离。

## 数值修改

`Assets/PKBall/Resources/PrototypeBalance.asset`：质量、速度、撞击、能量与超时规则。`Assets/PKBall/Resources/Weapons/*.asset`：近远程冷却、伤害、射程与冲撞倍率。脚本都在 `Assets/PKBall/Scripts/`，Editor 场景生成器在 `Assets/PKBall/Editor/`。

## 当前边界

这是 M0 战斗玩具，不包含商店、仓库、4→6→8→10 扩格、格位强化、每日事件、锻体或存档。这些在设计文档中有规则，下一阶段从 M1 开始接入。当前 AI 只进行一次简单发射，没有多对手决策。战斗平衡尚待 Unity 实际试玩调整。

## Windows 测试版

也可以直接运行 Builds/Prototype/PKBall.exe。此目录中的 PKBall_Data、UnityPlayer.dll 等文件与可执行文件一起构成完整程序，移动时应保持同目录结构。2026-09-28 的构建已通过无图形设备自动战斗启动检查；画面效果仍需在 Unity 编辑器或有图形设备的 Windows 环境中试玩确认。
