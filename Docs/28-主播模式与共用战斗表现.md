# 28 · 主播单挑与共用表现系统

## 1. 入口和模式边界

主页新增 **主播模式**。点击进入双方配置页面，使用红方/蓝方页签分别编辑；两方均有 8 个可见装备格；旧版10格预设保留扩展装备入口。点击“开始单挑”直接加载既有圆形战场，自动弹射。支持战斗中切换 1×/2×、重播以及返回配置页。对局结束保留战场结果，不自动跳回准备阶段。

- 配置可保存为多个具名 JSON 预设，使用下拉菜单重新载入。
- 可设置双方名称、角色图像、基础生命、速度、初始护盾、伤害加成和直伤减免。
- 每件装备可设置等级、基础伤害、冷却、武器攻击距离、武器长度、光效大小、装备生命/速度、特殊效果倍率。
- 界面留空使用目录默认属性（JSON 内部用 `-1` 表示）。基础伤害、装备生命/速度仍按等级 1/2/4/8 倍计算；不是填写最终伤害。
- 特殊效果倍率影响毒、火、盾、治疗等效果数值和每次释放成长量；宗师固定百分比冷却规则仍使用现有等级规则。
- 角色生命字段是本体基础，装备生命额外加算；准备页说明和战场生命数值一致。
- 图像选项读取已有角色/怪物资源；新增图像放入 `Resources/Art`，角色图像扩展可通过 `visualId` 配置。当前不提供任意本地文件导入按钮。

主模式的对局对象保存在单独会话引用中，主播战斗使用临时对局；不会调用主模式胜败、扣精力、历史归档或写入主模式存档。返回时恢复原对象。战斗内装备定义也使用独立克隆，覆盖伤害不会污染商店目录或另一方。重播从配置重建，清除上一场临时叠层。

## 2. 两个模式共用道具和表现

主播模式只是配置入口；`PrototypeActor`、攻击调度器、弹道、碰撞、毒火盾和 `PrototypeCombatPresentation` 完全共用。没有另一套“主播伤害”。新道具直接加入全局目录，主模式照常受价格、稀有度、天数及商店等级约束。

新增三个表现原型：

| 道具 | 稀有度 | 一级价格 | 一级伤害/冷却 | 表现 |
|---|---|---:|---|---|
| 星落剑阵 | 传说 | 38 | 48 / 8秒 | 周围生成12把剑向目标汇聚 |
| 棱镜光束 | 史诗 | 26 | 24 / 4秒 | 快速追踪弹道与短暂蓝色光束 |
| 震荡战锤 | 稀有 | 18 | 25 / 4秒 | 原近战判定与扩散冲击环 |

现阶段沿用既有剑、弩、锤图标，属于可玩的表现原型；尚非独立绘制的新武器美术。剑阵是一次攻击的多剑视觉，48伤害是整次攻击总量，不是每把剑48。冲击环不额外扩大伤害范围，也不产生未经配置的群体伤害。

## 3. JSON 数据结构与迁移

### 道具目录

`Assets/PKBall/Resources/Data/items.json` 是现在的数值和表现配置入口，运行时通过 `PrototypeItemRepository` 读取。它包含全部既有道具及新增道具。

- `version`：目录版本，当前2（兼容1）。
- `assetId`：用于寻找原来的 ScriptableObject 素材绑定；可以复用别的道具图标/模型。
- `item.itemId`：稳定身份；旧存档使用这个 ID 还原道具。不能为了改名称而改变它。
- `item`：稀有度、价格、基础属性、生产周期、效果、分类等完整数值。
- `hasWeapon`：显式表示是否有武器，避免 JsonUtility 将 null 类数据复原为默认对象。
- `weapon`：伤害、冷却、距离、弹速、攻击形态、动画时间、视觉类型等；没有武器时为 null。
- `weapon.visualScale`：旧版武器释放图像倍率，保留兼容；不改变碰撞半径或攻击距离。
- `weapon.visualSize`：武器长度（世界单位），0.1～6，独立于攻击距离。
- `weapon.effectScale`：光束和冲击环大小，独立于武器长度。
- `weapon.visualStyle`：0单次挥击/发射、1剑阵齐射、2光束、3冲击环。
- `weapon.visualCount`：剑阵视觉数量，1～24；没有暗含伤害倍率。

ScriptableObject 保留为 Unity 素材引用的载体，模型 Prefab、贴图和原始备用定义无需转为 JSON 文件路径；目录优先覆盖数值。旧对局 JSON v5 结构保留，历史存档继续读取成长、吞并效果、药剂配方、叠层、金币、精力和保命记录。目录 JSON 错误时明确警告并退回原始素材定义。

重启游戏/重新进入 Play 后生效；当前不支持战斗途中热加载目录。已有道具实例的永久成长仍保存在对局存档中，不写回道具目录。JSON 目录与玩家存档各有用途。

### 主播预设

位置：`Application.persistentDataPath/broadcast-presets/<配置名>.json`。Windows 通常在 AppData/LocalLow 下的公司名/产品名目录中；用户界面仅显示预设名，不显示文件路径。

角色预设另存于 `broadcast-characters`，配置页可保存当前一方的角色并从角色列表载入到任意一方；包含角色属性、外观及全部装备。

写入先生成 `.tmp`，再原子替换旧文件并保留 `.bak`。读取时检查版本、未知道具、空角色、等级、非有限数值以及数值范围。错误显示在配置页，不启动损坏对战。预设保存采用同步写入，因为仅在配置页人为点击保存，数据量小，不发生在战斗帧中。

`Docs/broadcast-example.json` 提供“剑阵与药剂”的完整双方配置示例，可复制到上述预设目录。当前没有导出录制视频或直播平台连接功能。

## 4. 表现系统如何工作

攻击分为三个步骤：**满足释放条件 → 快照攻击数据并进入冷却 → 弹道到达或挥击延迟结束后结算**。

动画只订阅释放行为，不决定伤害。近战需要到达攻击距离，远程冷却完成后追踪目标。视觉大小、数量、透明度和动画时间由表现配置决定，冷却和伤害仍由战斗时钟决定。常态仅显示正立的角色图像，释放时才显示武器。

当前使用参数驱动的池化动画：32个激活效果槽、复用 SpriteRenderer/LineRenderer、共用材质、复用伤害数字。齐射轨迹由释放时间插值，光束与冲击环复用线条。视觉池不足可以略过装饰，攻击调度仍照常结算，不丢伤害事件。2倍速使用同一个战斗时间推进，动画、弹道和冷却同步。

后续路线：

1. 将视觉参数独立为 `AttackVisualProfile`，含预备、释放、飞行、命中四个阶段及多个效果通道，允许一个道具组合多种效果。
2. 有骨骼角色时用 Animator 做角色动作和手持姿态；现阶段球体和二维图像不需要骨骼才能实现剑阵。
3. 复杂特写可以用 Timeline 编排镜头、音效和全屏光效。关键伤害时点仍由攻击调度器控制，不依赖动画事件是否触发。
4. URP 的粒子、Shader Graph 或 VFX Graph 用于火焰、雷电和全屏光效；控制最大实例数、发射数量、透明叠层及光效强度，并提供简化表现开关。
5. 每个效果通过释放 ID / 来源角色 / 目标 / 时间参数关联；池对象重用时清理目标、进度、材质参数和事件订阅。

目前已实现参数化剑阵/光束/冲击环，不宣称已有完整 Timeline、Animator 或 VFX Graph 系统。视频 BV1n88n6MEAD 本轮访问失败，无法据此复刻具体镜头；可根据后续截图或视频再调整表现节奏。

## 5. 毒火延迟血条和稀有度

实际生命条立即更新，下面的损血残条停留0.22秒后退去。毒伤用绿色，火伤及一般伤害用红色。治疗向上更新时残条同步增加，不形成假伤害。延迟仅属于显示，不影响伤害、胜负或存档。颜色依据实际扣血的伤害类型，完全被盾吸收时不制造生命损失特效。

稀有度沿用普通/稀有/史诗/传说四级，分别为灰蓝/蓝/紫/金。战斗双方道具格使用轻微底色与等级字色；背包格有底色与文字颜色，商店显示带颜色的稀有度文字。装备环保留格子附魔颜色，避免用稀有度覆盖附魔信息。使用现有 UGUI 图像和颜色，不为每格额外堆积大边框。

## 6. 本轮验证

- Unity 编辑器真实 Play 模式：主页入口、双方切换、目录下拉展开、自动开战、双方道具悬停、2倍速、重播、战后停留及返回配置页通过。
- 对战预设与角色预设保存/载入、覆盖保存、独立属性克隆、拒绝非法数值通过。
- 原始道具逐项核对武器有无、生命加成与效果数量；旧对局成长、配方及继承属性恢复通过。
- 读取已有正式存档验证可解析；主播战斗前后主模式快照相同，未写入正式测试进度。
- 真实画面检查后，修复蓝方页签与装备区重叠、菜单透到配置页和角色预览透明问题。
- 剑阵默认武器长度0.62，常规近战0.85、远程0.65；独立的武器长度和光效大小覆盖参数验证通过。
- 新道具保留素材定义备用资产，JSON异常回退时仍可识别其稳定 ID，避免旧存档装备丢失。

本轮不包含直播平台推流、自动录屏、性能压力基准或 B 站视频镜头复刻。
