# 首季角色设定与录制卡

2026-10-13；数据源：`Resources/Data/characters.json`。共23个可载入角色（17个旧角色、6个新构筑）、8组对战。

## 共用世界观与强度

旧城毁于雷火事故，城防机械、山林灵物与幸存者争夺残留核心。普通是地方生存者，精英是成熟职业或族群强者，首领是古老灵物或城防级存在。小死神只是见习者，史莱姆只是局部群体，禁止把名字解读为绝对无敌。

主播故事档本体生命普通300、精英360、首领420；速度100/100/95，通常六件装备、余下两格空置（八团史莱姆八件，小死神四件，以百分比镰刀换取装备数量劣势）。普通装备均一级、已有首领核心固定四级，无隐藏增伤/减伤、无预填历史成长。装备附加生命仍另算。故事档跨档挑战不宣称公平。冒险仍使用原有按天/档位公式，不把主播生命覆盖过去。

## 拍摄步骤

主菜单 → 主播模式 → 对战预设中的【首季】条目 → 检查红蓝装备 → 开始。角色区的【内置·档位】条目可单独换一方；用户保存条目有独立【我的】前缀。载入是副本，保存仍保存到个人文件，不修改内置目录。所有基础、词条、成长、吸收、音效、动画区继续使用原编辑器。新角色可通过“加入怪物池”保存为自定义野怪。

录制先做一次完整试打，讲清装备等级、档位、是否有历史成长；剪辑保留逆转的触发原因。建议每组交换左右各试3场再选素材，避免把单局当胜率。前八期只发布机制观察，暂不做绝对战力排行。新立绘制作前明确标记“试作角色/复用外观”。
