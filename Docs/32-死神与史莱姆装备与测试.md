# 死神与史莱姆：装备、素材及测试

## 规则

- 死神镰刀：首领专属、固定四级，不在商店出售，9 秒冷却，12 攻击距离（录屏表现更新）；释放时快照敌人最大生命值的 1/3，20% 暴击概率、双倍暴击。直伤正常受护盾、直伤减免影响。百分比不随装备等级翻倍。
- 死神披风：野外普通装备、支持一至四级，不在商店出售，7 秒冷却，释放后 1 秒无敌。免疫直接伤害、碰撞、毒火伤害以及新的毒火附加；已有毒火计时仍推进。无敌结束自动恢复受伤能力，显示半透明青蓝色护罩。
- 史莱姆粘液：稀有，12 金，5 秒冷却。每次先增加当前最大生命的 5%，当前生命同步增加等量（保留已损失生命量），然后造成新的自身最大生命值 5% 的直伤。本场临时成长，不写入角色永久属性。八件装备分别结算，同轮上限乘以 1.05^8 ≈ 1.47746。
- 骨珠护符：普通，8 金，6 秒冷却，每次护盾 +8（按装备等级翻倍）。死神其余位置使用此类低强度装备和缓冲垫。
- 百分比和无敌持续时间保持定义值，避免高等级镰刀直接变成数倍最大生命。吸收装备按吸收贡献比例保留这些效果。

## 怪物

小死神作为首领候选之一，携带镰刀、披风、骨珠护符、缓冲垫。八团史莱姆作为精英候选之一，一件首领史莱姆核心与七件粘液。每天仍各难度随机抽一个，新增怪物共享原有按天数递增的生命预算。

三个特色装备和骨珠护符都可在主模式及主播模式使用，野怪胜利可从携带的装备中掉落。镰刀和披风只通过野怪掉落获取；粘液属于野外装备，骨珠护符按稀有度进入商店。冷却、距离、图像、音效仍走共用配置。
